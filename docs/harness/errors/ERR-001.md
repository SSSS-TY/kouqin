# ERR-001: 在工作区执行 `git init` 导致沙盒环境刷新失败，全部命令无法启动

- **发现时间**: 2026-09-25
- **发现者**: Agent
- **状态**: Resolved
- **影响范围**: 整个工作区的命令执行能力（命令工具完全不可用）；仓库文件内容未受影响
- **关联任务**: 口琴自动演奏宏 v1 —— 工程初始化
- **关联决策**: N/A

## 错误现象

在 `D:\codex\kouqin` 执行 `git init` **成功**（输出 `Initialized empty Git repository in D:/codex/kouqin/.git/`）。
从**下一条命令**开始，每次调用命令工具都返回：

```text
Failed to create unified exec process: helper_unknown_error: setup refresh had errors
```

失败与工作目录无关：在 `D:\codex\kouqin`、`D:\codex` 下执行同样失败；因此并非某条命令的问题。

## 复现步骤

1. 在沙盒内的空目录执行 `git init`。
2. 执行任意命令（如 `Get-Location`）。
3. 观察结果：`setup refresh had errors`。

## 分析过程

- **假设 1**: `.git` 目录由沙盒账户创建，其 DACL 无法被 setup 更新，导致每次命令前的环境刷新失败
  （与同目录工程 `ssj_yq` 的 ERR-001 同源）。
  - **验证方法**: 删除 `.git` 后立刻重试普通命令。
  - **结果**: 假设成立。删除后普通命令立即恢复正常。

## 已尝试方案

### 尝试 1

- **修改或操作**: 原地重试命令；改用其他工作目录重试。
- **结果**: 均失败。
- **新证据**: 失败与工作目录无关 → 属于工作区级（`.git`）问题，而非命令或 shell 问题。

### 尝试 2

- **修改或操作**: 申请提权，删除刚创建的空仓库目录 `D:\codex\kouqin\.git`。
- **结果**: 成功；`Test-Path` 返回 `False`；随后普通（非提权）命令恢复正常。
- **新证据**: 环境恢复与 `.git` 的存在严格相关。

## 根本原因

沙盒在每次命令前会对工作区 `.git` 施加 deny ACE。若 `.git` 由沙盒账户自身创建，setup 无法更新其 DACL，
环境刷新即报错，命令全部无法启动。

## 修复方案

**不在本工作区内执行 `git init`。** 若需要版本控制，由**用户在自己的终端**中初始化仓库
（用户账户创建的 `.git` 具有可被正常继承与更新的 DACL）。

## 验证方法

```powershell
Test-Path D:\codex\kouqin\.git
```

预期结果：`False`（未初始化）。若用户已自行初始化，则应为 `True` 且命令工具保持正常。
